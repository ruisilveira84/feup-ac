## Project Description

Basketball tournaments are typically divided into two phases. In the first phase, all teams compete against each other, striving to accumulate the highest number of wins. At the end of this phase, a predetermined number of teams with the most victories qualify for the playoffs, where they face off in a series of knock-out matches to compete for the championship.

Over the past 10 years, data has been collected on players, teams, coaches, games, and various other metrics, all organized in this dataset. The objective is to use this data to predict which teams will qualify for the playoffs in the upcoming season.

## Requirements

### **1. Python and Libraries**

To set up the project, ensure you have Python 3.7 or later installed.

The required Python libraries are listed in the `requirements.txt` file. To install them, follow these steps:

### **2. Setup Instructions**

#### **Step 1: Clone the Repository**
```bash
git clone <repository-url>
cd <repository-folder>
```

#### **Step 2: Create a Virtual Environment (Recommended)**

- **On Linux/macOS:**

  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```
- **On Windows:**

  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```

#### **Step 3: Install the Requirements**

```bash
pip install -r requirements.txt
```

#### **Step 4: Run Jupyter Notebook**

Navigate to the `notebooks` folder and start the Jupyter Notebook server:

```bash
jupyter notebook
```

#### **Step 5: Run the Project**

Navigate to the `src` folder and execute the `main.py` file:
```bash
python src/main.py
```
